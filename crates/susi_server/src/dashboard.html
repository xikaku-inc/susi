Newsletter

Gmail connection

not connected

Campaign mail is sent over Gmail with OAuth, so no app password is stored on the server. Account email - sign-in codes, password resets - keeps using its own relay.

Newsletter sending is not configured. Set SUSI_NEWSLETTER_SMTP_HOST, SUSI_NEWSLETTER_SMTP_USER, SUSI_NEWSLETTER_SMTP_PASSWORD and SUSI_NEWSLETTER_SMTP_FROM_ADDR in the host environment and restart. Campaign mail deliberately uses its own credentials and never falls back to the account-email relay, so a campaign cannot affect sign-in codes or password resets. Drafts can still be written and previewed.
